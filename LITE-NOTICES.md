AstroAmase Lite modifies Astro AMASE revision `651a2e47ffe1acaca2c139a9bc963779bf9fbbcc`. The November 20, 2026 changes cover active-catalog selection, fitting, exports, replay, and the notebook workflow. The combined software includes simulation code derived from molsim and is distributed under the [GNU General Public License, version 3](licenses/molsim-GPL-3.0.txt). The original Astro AMASE [MIT license and copyright notice](LICENSE) remain in effect for the upstream material. This branch contains the editable analysis source and notebook cells. Each run records the embedded analysis source and its checksum under `environment/`. [Fried et al. (2026)](https://doi.org/10.3847/1538-4357/ae9a8e) · [Astro AMASE](https://github.com/zfried/astro_amase/tree/651a2e47ffe1acaca2c139a9bc963779bf9fbbcc) · [molsim](https://github.com/bmcguir2/molsim/tree/de50971151bf215d35255ee3ae348ba250113ac7)

The catalog source is Zachary T. P. Fried's *Required Files for Astro Amase*, version 1. The deposit lists CC BY 4.0. Lite downloads source files directly, selects catalog objects and rebuilds their indexes. Draft 02 includes normalization repairs for 18 JPL entries. The recipe records the source evidence, partition values and numeric corrections used to rebuild those entries. The active manifest records the CDMS and JPL tags, state coverage and available provenance. Cite the original spectroscopy sources for the catalogs used in an analysis. [Zenodo deposit](https://doi.org/10.5281/zenodo.21171085) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [CDMS (2001)](https://doi.org/10.1051/0004-6361:20010367) · [CDMS (2005)](https://doi.org/10.1016/j.molstruc.2005.01.027) · [JPL catalog](https://doi.org/10.1016/S0022-4073(98)00091-0)

The PILS candidates reconstruct laboratory spectroscopy from its originating providers. The methyl formate model uses Lille tag 60802 and the tabulated LTE partition function in Carvajal et al. The extended selection also uses main methanol from CDMS 032504 and glycolaldehyde from CDMS 060501, 060529, 060530 and 060531. The active manifest and reconstruction files in each result identify each model, covered states and sources.
