## Software and catalog credits

AstroAmase Lite uses Astro AMASE at revision `651a2e47ffe1acaca2c139a9bc963779bf9fbbcc`, with Lite changes to catalog handling, fitting and output. Its source includes simulation code derived from molsim. The source bundle contains the Astro AMASE license and the GPL version 3 license from molsim. The run records the source bundle and its checksum under `environment/`. [Fried et al. (2026)](https://doi.org/10.3847/1538-4357/ae9a8e) · [Astro AMASE](https://github.com/zfried/astro_amase/tree/651a2e47ffe1acaca2c139a9bc963779bf9fbbcc) · [molsim](https://github.com/bmcguir2/molsim/tree/de50971151bf215d35255ee3ae348ba250113ac7)

The catalog source is Zachary T. P. Fried's *Required Files for Astro Amase*, version 1. The deposit lists CC BY 4.0. Lite selects catalog objects and rebuilds their indexes. Draft 02 also repairs the partition-function normalization for selected JPL objects. The active manifest records the CDMS and JPL tags, state coverage and available provenance. Consult the original experimental or theoretical references for the catalogs used in your analysis. [Zenodo deposit](https://doi.org/10.5281/zenodo.21171085) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [CDMS (2001)](https://doi.org/10.1051/0004-6361:20010367) · [CDMS (2005)](https://doi.org/10.1016/j.molstruc.2005.01.027) · [JPL catalog](https://doi.org/10.1016/S0022-4073(98)00091-0)

The PILS candidates reconstruct laboratory spectroscopy from its originating providers. The methyl formate model uses Lille tag 60802 and the tabulated LTE partition function in Carvajal et al. The extended selection also uses main methanol from CDMS 032504 and glycolaldehyde from CDMS 060501, 060529, 060530 and 060531. The active manifest and reconstruction files in each result identify each model, covered states and sources. [Lille Spectroscopic Database](https://lsd.univ-lille.fr/) · [Methyl formate partition reference](https://doi.org/10.1051/0004-6361/201935469) · [Cologne Database for Molecular Spectroscopy](https://cdms.astro.uni-koeln.de/)
